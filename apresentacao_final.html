Problema escolhido

Classificacao de doencas em folhas de plantas

Como transformar uma foto de folha em uma previsao objetiva sobre saude ou doenca usando redes neurais convolucionais?

TensorFlow PlantVillage MobileNetV2 38 classes
Equipe: Marley Abe Silva, Luis Pedro de Castro Alves e Maycon Moriy Abe Machado
Abrir com o problema concreto: uma decisao agricola depende de identificar sinais visuais cedo. A historia da apresentacao segue problema, dados, metodo, evidencia e conclusao.
1. Contexto Por que este problema importa?

A folha e um dos primeiros lugares onde a planta mostra sinais de estresse. O desafio e transformar esse sinal visual em uma classificacao consistente.

Impacto pratico

Identificar doencas mais cedo pode apoiar manejo, triagem e acompanhamento.

Problema visual

Manchas, cores e textura variam entre especies, doencas e folhas saudaveis.

Objetivo tecnico

Treinar um classificador que receba uma imagem e retorne uma das 38 classes.

Mensagem central: automatizar uma leitura visual, mas com consciencia das limitacoes.
2. Motivacao Por que usar Deep Learning?

O problema nao e apenas detectar uma mancha

A mesma doenca pode aparecer com intensidade diferente, e classes diferentes podem compartilhar padroes visuais parecidos.

1

Extrair caracteristicas manualmente seria fragil para 38 classes.

2

CNNs aprendem padroes de borda, cor, textura e forma diretamente das imagens.

3

Transfer learning aproveita conhecimento visual aprendido em grandes bases.

Decisao: comparar baseline simples com MobileNetV2 pre-treinada.
3. Dataset PlantVillage via TensorFlow Datasets

Uma base grande, organizada e adequada para classificacao supervisionada

54.303 imagens no experimento completo

224 pixels por lado na entrada do modelo

Split deterministico com seed fixa para permitir reproducao.
4. Pipeline Do dado bruto ao tensor de treino

O pipeline foi desenhado para ser reproduzivel e leve

Depois de um problema de consumo excessivo de recursos, limitamos explicitamente paralelismo, shuffle, prefetch e memoria da GPU.

A

Carregar PlantVillage com `tfds.load` e `shuffle_files=False`.

B

Aplicar split 70/15/15 com seed fixa.

C

Redimensionar para 224x224 e converter para `float32`.

D

Aplicar aumento de dados apenas durante treino.

Boas praticas: determinismo, validacao de config e uso conservador de recursos.
5. Modelo escolhido MobileNetV2 com transfer learning

Por que MobileNetV2?

  • Boa relacao entre desempenho e custo computacional.
  • Arquitetura adequada para imagens 224x224.
  • Pesos pre-treinados no ImageNet aceleram o aprendizado.
  • Camada final adaptada para 38 classes do PlantVillage.
Componente Funcao
Data augmentation Reduzir dependencia de variacoes simples da imagem
MobileNetV2 Extrair caracteristicas visuais
GlobalAveragePooling2D Condensar mapas de caracteristicas
Dropout Reduzir overfitting
Dense softmax Gerar probabilidade para 38 classes
Tambem existe uma CNN baseline no codigo para comparacao e validacao.
6. Treinamento Experimento final

Treinamos com GPU, mas com limites para preservar a maquina

20 epocas
8 batch size
2 CPUs no Docker
8 GB limite de RAM

Callbacks

  • Checkpoint pelo melhor `val_accuracy`.
  • EarlyStopping monitorando `val_loss`.
  • ReduceLROnPlateau para reduzir learning rate.
GPU reduziu a primeira epoca de aproximadamente 944s para 111s.
O treino completo gerou modelo, historico, grafico e metadados.

8. Metricas usadas Resultado no conjunto de teste

O desempenho final foi medido em dados separados do treino

95,40% accuracy
94,41% macro F1
95,36% weighted F1

Por que accuracy?

Mede o percentual total de acertos e e facil de comunicar.

Por que F1?

Combina precision e recall, ajudando a enxergar desempenho alem do acerto bruto.

Teste com 8.146 imagens nunca usadas para treinar os pesos.
